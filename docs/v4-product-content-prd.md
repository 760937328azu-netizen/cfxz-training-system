# 长发小寨新人入职培训系统 V4

## 1. 产品定义

这不是课程平台、员工手册电子版或儿童游戏，而是一段由小瑶陪伴新人完成的「长发小寨认知成长旅程」。

完成六关后，新人应能够回答：

1. 我加入的是一家什么公司；
2. 公司的文化根源在哪里；
3. 产品为什么这样做；
4. 公司如何协作和运转；
5. 我进入公司后应该怎样工作；
6. 我如何完成认证并开始后续学习。

## 2. 冻结项

- 六关名称、顺序和徽章；
- GrowthMap 3D 微缩地图、浅色侧边栏和页面路由；
- 顺序解锁、认证后开放学习天地的逻辑；
- 小瑶作为旅程伙伴，而不是客服或页面装饰；
- 中文排版硬规范与事实审核机制。

## 3. 六关内容

### 01 欢迎加入

目标：建立新人身份、陪伴关系和六关旅程期待。页面由欢迎 Hero、小瑶介绍、学习目的和六关预览组成。点击「好呀，一起出发！」完成第一关。`journey_map` 音频必须按 V4 重录。

### 02 认识长发小寨

回答「我加入的是一家什么样的公司？」包括：

- 公司全貌：文化传承、科技研发、品牌创新；
- 企业历程：只保留品牌起源、科研合作、科技馆建设、产品发展、渠道成长和未来规划等关键节点；
- 公司组织地图：职能支持、销售增长、项目创新三类体系；
- 遇到问题找谁：将报销、流程、产品问题等映射到协作部门；
- 愿景、使命、价值观：通过行为判断理解先公后私、真诚利他、高效进取、敢做敢当。

年份、荣誉、部门负责人、部门职责均需正式资料审核。

### 03 认识品牌与非遗文化

回答「我们的品牌根在哪里？」采用数字文化馆体验：

1. 红瑶长发文化：真实人物、生活、长发意义及闺中秀、螺丝发、乌龙盘发；
2. Logo 故事：乌龙盘发 → 轮廓提取 → 品牌 Logo；
3. 非遗淘米水：取米 → 淘洗 → 发酵 → 检查 → 提取；
4. 中国长发科技馆：文化展示、技艺传播、科研成果展示与社会价值连接。

真实人物、发式图片、Logo 来源、科技馆成果和科研数据没有审核资料时必须保持 `pendingReview`。

### 04 认识产品与核心技术

回答「为什么长发小寨能做这些产品？」内容顺序固定为：

1. 消费者问题：头皮、发根、发丝，以及掉发与断发的区别；
2. 产品底层逻辑：消费者问题 → 问题位置 → 产品机会 → 产品定义 → 研发设计 → 市场验证 → 持续优化；
3. 米水气技：龙参米、当地水源环境、龙脊自然环境、传统发酵智慧与现代技术；
4. 产品体系：防脱固发、头皮清洁、分型养护、沙龙奢护；
5. 重点产品：解决什么问题、属于哪个体系、核心价值；
6. 产品问答：答案必须带解释，不做复杂游戏。

产品名称、功效、技术结论和参数必须来自正式产品资料及《产品跑分表V3调整版》。

### 05 认识组织与基础制度

回答「我进入公司以后如何工作？」主线为「新人的一天」：

- 组织协作复习：部门、岗位、直属负责人、协作对象；
- 工作场景：上班打卡、请假、外出与出差、报销、加班、异常处理；
- 办公系统：Moka、OA、企业微信、云之家；
- 文化行为标准：先公后私、真诚利他、高效进取、敢做敢当。

练习流程固定为：场景 → 判断 → 提交 → 小瑶反馈 → 正确处理方式。所有制度细则必须等待现行制度审核。

### 06 完成新人认证

这不是课程，而是学习验证、风险发现和培训留痕：

1. 六关回顾与成长印记；
2. 覆盖公司文化、产品认知、制度流程的整卷考试；
3. 整卷提交后查看总成绩、薄弱领域和错题回顾；
4. 必要时返回对应关卡复习并再次认证；
5. 通过后点亮第六枚徽章、生成新人证书并解锁学习天地。

禁止逐题公布正式考试答案。题库、分数线、次数规则和证书字段全部需要业务确认。

## 4. 学习天地

认证前只做未来空间预告；认证通过后开放产品深入、企业文化、岗位成长和专业能力。V4 当前不扩建完整 LMS。

## 5. 小瑶使用规范

- 开场：全身透明人物，建立陪伴关系；
- 关键节点：场景导游或短反馈；
- 总结：回顾本站记忆点；
- 问答：用户主动打开的头像入口。

同一屏幕禁止重复出现多个小瑶，普通小头像禁止塞入全身图。

## 6. 统一体验规则

- 基础流程：内容展示 → 小瑶引导 → 产品或知识问答 → 完成并记录进度；
- 不用大段 PPT 文本，不堆同级卡片，不制造儿童化游戏机制；
- 每页必须有大视觉、故事层、知识层、互动层和总结层的节奏变化；
- 中文标题和关键文案执行 `docs/chinese-typography-standard.md`；
- 未经审核的事实使用 `factStatus: "pendingReview"`，不得从旧稿或常识推断。

## 7. 数据来源与交付顺序

正式内容按以下资料逐步替换：企业历程、组织架构、产品跑分表、现行制度、题库、证书模板、小瑶音频、真实文化图片及 VR 素材。

开发不再重新讨论六关结构，只在本 PRD 和 `src/data/v4ContentPlan.ts` 的契约内补充素材、事实、页面和互动。
