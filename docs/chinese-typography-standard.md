# 中文界面排版硬规范

> 中文界面不是把文字塞进固定尺寸的卡片，而是让容器服务于中文阅读。

## 强制规则

- 页面标题、模块标题、卡片标题、关卡标题、地图说明和关键文案，禁止末行只剩 1～3 个汉字。
- 标题优先单行；必须换行时不超过两行，并保持两行视觉长度接近。
- 正文允许自然换行；两行正文的末行宽度不应低于首行的 30%。
- 换行必须尊重中文短语和语义停顿，不使用随意的 `<br />` 拆开完整词组。
- 处理顺序固定为：调整容器宽度 → 调整字号或字距 → 优化文案 → 最后才允许按完整语义人工换行。
- 宁可调整容器，也不允许留下孤字；宁可减少容器，也不把页面切成卡片碎片。

## CSS 基线

全局标题使用 `text-wrap: balance`，正文使用 `text-wrap: pretty`，并统一启用：

```css
word-break: normal;
overflow-wrap: break-word;
line-break: strict;
```

关键中文节点使用 `.zh-title`、`.zh-body` 和 `data-typography-check` 标记。

## 回归检查

执行：

```bash
npm run test:typography
```

测试覆盖 1440、1600、1920 三档桌面视口，并逐字符读取浏览器实际换行。以下情况直接失败：

- 末行只有 1～3 个汉字；
- 两行正文末行宽度不足首行 30%。

该失败统一定义为 `Chinese typography regression`，视觉改版后必须与构建和 GrowthMap 回归一起执行。
