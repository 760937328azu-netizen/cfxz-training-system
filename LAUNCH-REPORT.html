5. 生产安全配置清单

  • 密钥只在后端 env — JWT_SECRET、DATABASE_URL 只在 server/.env
  • .env 不提交仓库 — .gitignore 已排除所有 .env 文件
  • 前端不含密钥 — 仅通过 /api 相对路径访问
  • CORS 限制 — CORS_ORIGINS 环境变量控制
  • 权限后端校验 — authenticate + requireAdmin + requireSuper
  • 关闭错误堆栈 — 生产环境返回通用错误消息
  • 登录限流 — 15 分钟 10 次，超限返回 429
  • 全局 API 限流 — 每分钟 100 次
  • Helmet 安全头 — XSS 防护/点击劫持防护/CSP
  • JWT 7 天过期 + bcrypt 12 轮哈希
  • Seed 密码检查 — 生产环境禁止默认密码

6. localStorage Key 审计

Key用途是否数据源
cfxz-auth-token员工 JWT Token否（认证缓存）
cfxz-admin-auth-token管理员 JWT Token否（认证缓存）
cfxz-user-session员工会话缓存否（数据库为准）
cfxz-admin-session管理员会话缓存否（数据库为准）
cfxz-admin-store后台降级模式缓存否（API 优先）
cfxz-phase3-learning-progress-v2-*学习进度缓存否（数据库为准）
结论：所有 localStorage Key 均为缓存/会话用途，数据库为唯一数据源。
